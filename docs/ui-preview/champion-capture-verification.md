# 抢状元与牌桌互动验收

## 抢状元

状元奖池为0时，确认状元骰型会比较其他玩家所持最低等级状元，严格更大才抢，同档不抢。最低档多份随机取一份，转移后更新为新骰型等级。每份仍1000分，奖池与总状元份数不变。

不抢自己的状元；不经过护罩、反弹、替身、B护奖，不消耗它们。姻缘仍分担真实得失，转移不重复加财神奖金。未抢成功时灶君未中奖补给正常触发。

## 正式牌桌动画

- 来源与目标绑定正式PaperGame的6个人物锚点；自己在牌桌中有专门座位头像，飞行不再指向底部操作栏。
- 奖项从原持有人飞到新持有人，出招、反弹、替身、最终防护依次播放。初始攻击显示“出招中”，实际防护后显示“已抵挡”。
- 全32技能及神明供奉、持续掷骰影响、姻缘分账、场地逐人作用、金币补给记录结构化事件。
- 每条1100ms，自动回合等待队列逐条确认；减少动态模式550ms静态展示。
- 手动popover使动画能显示在原生手牌dialog上方，不拦截鼠标、不抢键盘焦点。
- 独立interaction-replay页面和入口已移除，交付在正式游戏中展示。

## 检查

修改前抢状元7项中5项失败；修改后新增检查46项通过，连同原90项共136项通过。临时检查涵盖32技能、等级/份数/分账、实际目标、自用牌忽略多余target、反弹/替身/防护链、ACK旧回调与自动推进时序、卸载清理等。临时文件按用户要求删除。

独立只读审查发现并修复：机器人自用牌多余targetId误导动画；抢状元失败跳过灶君补给。复核无剩余P1/P2。

浏览器正式对局验证了基础技能与领奖动画：真实牌桌锚点为wu/mei/chen/jie/lin/you，EffectLayer处于popover顶层且pointer-events:none，控制台无error/warn。截图table-interaction.jpg。动画组件额外验证静态、头像回退、自用光环与清理。

浏览器未通过强制改写对局来制造低概率抢状元；该分支由确定性规则检查覆盖。

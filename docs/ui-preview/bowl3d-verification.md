# 红釉金纹 3D 骰碗验收

2026-10-24。用户确认局部真 3D：红釉金纹碗＋立体骰子，保留现有国风界面。

## 实现

- 首页与对局共用 Three.js 场景，真实内外壁、金边与圈足，红釉和本地生成的金色花纹。六面圆角象牙骰子，一与四为红点。
- 固定斜俯视镜头，光照、反射、碗壁遮挡、骰子阴影在同一空间中呈现。翻滚按既定轨迹演出，规则提供最终骰点。
- 原有正常投掷、整碗重掷、单骰重投和改点继续使用原 props，支持场地的 4–8 骰。减少动态效果时直接呈现当前结果。
- WebGL 场景懒加载，额外生产文件约 136KB gzip；静止时退出逐帧循环。页面切换释放几何、纹理、灯光阴影和 WebGL 上下文。
- 无 WebGL、资源加载失败或上下文丢失时显示静态红金碗和原 SVG 骰面，可继续投掷及结算。辅助技术可读取当前骰点。

## 验证证据

- 97 项测试通过，其中本次临时检查 7 项：全部六种点数朝上、4–8 骰范围与间距、减少动态效果、局部状态传递、静态渲染停止、卸载释放、初始化失败和上下文丢失。
- 真实快速对局：正常投掷→看结果→整碗重掷→免费重掷第三颗→确认结果→电脑完成行动→轮间商店。每次真实投掷只增加一次计数，单骰重投的另五颗保持原点数，展示骰点与规则快照一致。
- 1280×1000、1280×720、390×844、320×740；手机从入局到投掷完整执行，结果自动滚到操作栏上方，没有横向溢出。
- 独立预览逐个核对 4、5、6、7、8 骰，第三颗 3→4 改点，减少动态效果，连续卸载重建四次、模拟上下文丢失。禁用 WebGL 的手机仍能完成投掷并进入确认结果。
- 网页游戏技能标准 Playwright 客户端完成两轮翻滚截图。正常路径页面及控制台错误 0；主动模拟上下文丢失时有一条预期回退日志。
- 独立只读代码审查未发现有证据的 P1/P2 问题。
- 本次临时测试与独立预览入口通过后删除；最终原有 90 项测试、生产构建（含 PWA 资源生成）与 git diff --check 均通过。

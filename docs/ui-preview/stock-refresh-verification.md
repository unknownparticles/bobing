# 八张货架与付费刷新验收

本记录替代早期完整56张商店的陈列方式说明。完整牌库仍56种，但每人当前货架只有2神明、3技能、3场地。

- 牵羊由玩家选对手后随机夺取一份奖项，每份概率相等，连同内部状元等级转移。
- 每人独立货架，分类内不重复；新旧批次可以重复。买走售罄不补位，已购每种每轮限购保持。
- 全部8张刷新：5、10、15……金币，每轮商店重新从5开始。库存、供奉与场地提交不随刷新消失。
- 机器人只能从自身货架购买。刷新在规则层校验商店阶段、余额与玩家。
- 进入商店所需48次抽样随机输入由控制层一次传入，避免后排玩家货架退化为固定值。
- 场地背包独立展示全部持有场地，不受刷新后的货架约束。

## 实际验证

修改前8项临时检查中6项失败，证明旧规则缺少货架刷新与随机牵羊；修改后8项全部通过。连同已有90项，总98项通过。本次临时文件验证后已删除。

浏览器：显示2/3/3，共8张；100金币刷新后95，下一次10金币。购买七星高照100→70，刷新70→65，仍可在场地背包选择七星高照提交候选。320、390像素无横向溢出。

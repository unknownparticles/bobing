## 已落地

- 品牌入口复用现有骰碗SVG，与网页标签、安装图标保持一致。核对16/32px favicon、180px Apple Touch及192/512px PWA图标实际尺寸，资源均存在。
- 模式卡、主操作、次操作、禁用状态、按下反馈及键盘焦点统一。浏览器确认3px键盘焦点、悬停变化、选中语义和44×44关闭按钮。
- 手牌列表、选择详情和技能横幅复用商品插画，保持16:9完整缩放。插画基础CSS归属到ShopArtwork，独立预览也能正确缩放；未配图的新增商品继续显示自身矢量徽记。
- 六类动效：改骰青瓷环、转移奖章/攻击冲击、防御护盾、反弹/替身回旋、祝福/牵缘印记、场地波纹。技能卡面与来源、目标、结果一起显示。
- 抵挡、改向优先于普通表现；未结算攻击保留“出招中”，不显示命中装饰。资源转移结果显示获得者收到奖章，已生效干扰施法使用攻击表现。
- 动效持续时间读取现有VISUAL_DURATION_MS，事件队列与结算未改动；并行加入的真实骰点变化动画分支保留。减弱动画偏好下保留静态信息。
- 短桌面压缩辅助区与装饰，仍预留台词空间。1280×720双人桌操作区底边702px，六人故事桌约706px。

本轮复用现有插画、SVG与Lucide，以CSS和SVG构建交互动画，未增加依赖或发出新的生图请求。

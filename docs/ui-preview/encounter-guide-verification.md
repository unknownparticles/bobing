# 遇见图鉴与玩家详情验收

用户确认范围：本人货架与获得内容、全桌公开使用卡牌、入桌角色和公开技能跨局记录；对手未使用手牌不展示。

## 实现

- 首页和对局共用卡牌、技能、角色图鉴，支持仅看遇见过的卡牌。
- 主角技能和章节职业技能直接读取规则定义；部门与公司职业数值分别记录。缺少立绘的角色仍有身份条目。
- 玩家按钮打开实时奖项总份数、六种奖项明细、积分、当前效果和已公开使用卡牌说明；故事对手详情共用公开状态生成函数。
- 对手获得和货架记录不进入图鉴；对手公开使用只增加发现，不记为本人使用或本人成就。尚未生效、尚未选择目标的供奉不提前展示。
- 原存档兼容新增字段；保存失败和较新存档只读保护保留。
- 模态层拦截摇一摇，关闭后恢复操作；查看期间隐藏顶层出牌动效，避免遮挡阅读。

# 掷骰效果动画验收

范围：雷公、倒霉贴、福神及其他运气候选；单骰、双骰、留红再博、主角免费重投；直接改点和镜像复制。

实现：规则保留真实候选，展示层逐次摇碗、落定、比较；改点分为旧点数收起、新点数亮起。局部重投不摇动整碗，指定骰以外的点数保持。改骰后收起手牌，播放期间禁止继续出牌或提前确认。场地/公开保底改变选中结果时追加改点步骤；候选不会额外推进正式投掷或预告。

视觉风格：精致的二维独立游戏UI，温暖而有奇遇感的新国风，结合闽南木雕、花砖、庙宇屋檐、祥云、朱砂印、红绳、青瓷。背景为深墨绿织物台面，四周有木制柜架和克制的黄铜包角；卡面为有细微纤维的暖米色纸张。朱砂红主按钮、青瓷绿色场地牌、鎏金神明边框、暖橙技能牌。对比鲜明，内容区明亮，避免整张图灰白、米黄糊成一片。不要霓虹赛博朋克，不要网页后台、办公仪表盘、电商列表感。

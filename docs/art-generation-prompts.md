## 使用与交付约定

- 下方每个代码块是一条完整提示词，可独立复制生成。
- 基础立绘先生成；表情版本需要上传对应基础立绘作为参考，再使用表情提示词。仅靠文字不能保证人物一致。
- 每张独立导出，不要生成角色合集、九宫格或带标注的总览图。
- 人物推荐 768×1024 PNG；场景尺寸见各条提示词。保留原始文件。
- 如果生成工具不支持透明通道，请输出纯色、与人物明显区分的背景，并注明需要抠图；不要把棋盘格画进图片冒充透明。
- 像素边缘应清楚；后续缩放使用最近邻采样，不要用模糊滤镜。先确认三张基础角色的实际游戏缩略效果，再批量扩展。
- 昵称、积分、技能标题、对话文字全部由游戏绘制，不要生成到图片里。
- 桌、碗、骰子、奖池图标、护盾、粒子由 SVG 或程序化动画实现，不在这批位图任务内。
- 角色形象不绑定玩家昵称；主角三种外观均可自由命名。

| 场景留白 | 对局背景中央和底部不拥挤，不影响桌面和操作栏 |
| 原图保留 | 保留生成原图，避免反复有损压缩 |

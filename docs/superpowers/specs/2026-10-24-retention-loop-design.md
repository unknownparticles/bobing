# 短局与复玩体验

用户已确认全部实施：8 轮终局、机器人加速、全员开局一张重掷券、跳过剧情与剩余轮数提示。

- 第 8 轮最后一名玩家完成结果确认后结算；所有人都有八次正式行动。前七轮保留金币与商店，第八轮不再进入商店。
- 以持有奖项积分排名，同分并列（1、1、3）。结算展示六人排名、持有奖项、本人结果及距离第一的分差。
- 再来一局保留昵称、头像、身份和静音设置，重置轮次、积分、金币、奖池、保护、采购记录和道具；每人重新领取一张开局重掷券。返回首页可重新选择角色。
- 终局拒绝掷骰、道具、购物、轮次推进与旧定时器动作，只有重开可以重置状态。
- 普通机器人使用短动画与短等待；夺取、保护反馈和状元结果保留阅读时间。玩家原有掷骰动画及重掷确认不缩短；商店和终局不持有自动推进计时器。
- 两幕剧情均可跳过。首页说明八轮争冠与开局赠券；桌面、商店持续提示当前进度，最后一轮突出收官目标。

继续使用 React reducer、Lucide、现有米纸主题，不引入依赖，不格式化无关代码。临时测试验证通过后删除，保留原有测试。目录无 Git 元数据，不初始化仓库或创建提交。

验收：真实运行八轮并结算、重开与返回首页；同分、最后一人逆转、重复动作、重掷作废旧结果、金币与奖池守恒；手机与桌面布局、焦点、控制台；生产构建与原有测试。

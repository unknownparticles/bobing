# 响应式图片资源

用户已选择响应式图片方案，范围是图片加载速度、按需加载、部署路径与复用。

为当前使用的七张角色立绘生成 384、768 像素宽的 WebP，保留原始 1152 像素宽图片。生成清单保存真实尺寸和带内容摘要的文件名。共享图片组件使用 srcset、sizes 和异步解码；资源路径统一经过 BASE_URL，兼容相对部署目录。

角色预览、剧情主图立即加载并提高优先级；角色选项按可见性加载。头像立即加载，sizes 计入既有 CSS 的 290% 放大。各页面继续使用同一角色 URL，交由浏览器复用缓存。旧素材引用及未知角色的现有处理继续兼容。

生成过程提供可重复执行的 Python/Pillow 脚本。原始图片不重新压缩，不调整现有布局；不预取全部角色，避免首页额外下载。新增的散列文件解决生成图片更新后的缓存区分。

验证包括候选图片尺寸与文件存在性、不同展示位置的加载策略、未知和旧素材行为、生产构建、现有测试，以及部署到 /bobing/ 子路径后的浏览器实际选图。临时测试通过后按仓库约定删除。

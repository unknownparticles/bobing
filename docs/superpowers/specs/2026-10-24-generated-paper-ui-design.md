## 对局页

米纸背景配墨绿正文，朱砂作为当前行动与主操作的强调色。五位对手、中央青瓷骰碗、右侧奖池与底部操作区沿用现有信息结构。细金边、云纹与纸张材质用于增强氛围，文字和骰点所在区域保持干净。

保留现有角色素材；参考图中生成的人物、示例数字、骰点与文案不替代实际状态。骰子继续使用可独立选择、可动画的现有组件。主操作区应清晰区分技能、重掷券、手牌和掷骰/确认结果。

## 商店

墨绿台面、米纸卡面、朱砂购买与离店操作。保留左侧盘缠、供奉槽、刷新和离店区，以及右侧两张神明、三张技能、三张场地的货架结构。

卡面采用能表达效果的独立插画，替代重复的图标构图。卡名、价格、库存、购买状态、使用时机与规则说明均由 React 根据实际配置渲染。插画与框体分别实现，不能把整张参考图直接用作页面。

参考图仅演示八种商品；实际商店仍从完整商品库刷新，未单独生成插画的商品必须继续显示既有可辨识图形，不能错误借用其他商品的含义。

## 边界与验证

- 保留规则层、回合流程、英雄能力、供奉、目标选择、购买、刷新与场地提交行为。
- 生成素材放入项目资源目录，提供适合网页的压缩版本；不向客户端提供 API Key，也不为游戏添加运行时生图请求。
- 只修改相关展示组件和样式，不格式化无关代码，不覆盖其他正在进行的修改。
- 桌面首屏操作可见；手机无横向溢出，价格、详情与购买操作清晰可用。
- 实施后执行生产构建和与改动相关的现有测试，并在实际浏览器检查对局、商店及购买详情。

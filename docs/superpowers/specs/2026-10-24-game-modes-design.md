# 三种模式与公司博饼故事线

用户通过选择器确认：故事夺冠晋级；快速模式玩家对电脑；故事每章与快速模式均为八轮；晋级时重置所有局内资源；经典模式保留卡牌、商店和主角技能，最后一份奖品领取后立即结算。

- 故事：第一章组内六人、第二章部门八人、第三章公司王中王十人。每章有独立的两幕开场、对话、对局目标和结算文案。按现有积分优先、同分比较状元等级的规则排名，并列第一也属于第一名。第一名解锁下一章，失利可重试本章；第三章夺冠呈现通关结局。
- 快速：一名玩家对一名电脑，八轮完整行动，直接进入对局，不经过故事开场。
- 经典：用户追加确认总人数为二到十人的整数，其余席位由电脑参与；没有回合上限，最后一份奖品发出后结束。未发完奖池时即使超过八轮仍能继续进入商店。输入与规则层统一限制人数，超大数、小数和空输入禁止开局。
- 首页提供三个明确入口，经典模式同时提供总人数输入。三种模式共用角色设置、卡牌、商店、判奖和排名；结算后重开保留模式和身份。
- 动态座位顺序支持二、六、八、十及自定义人数，换位、反转和优先行动继续遵循真实座位规则。电脑货架随机输入随人数扩展。
- 手机对手栏横向滚动，当前行动者自动进入可见区；首页、剧情、桌面和结算使用现有纸面主题。

选择共享 reducer 加模式配置，而非复制三套对局逻辑；前者让所有人数共用相同规则，避免卡牌修复出现模式差异。仅改首页文案的方案无法实现真实人数与终局条件，因此不采用。

验证：先添加临时规则测试，覆盖可变人数、八轮公平终局、经典超过八轮及最后一份奖品立即终局、座位场地和重开资源重置；再验证故事晋级与失利、三模式入口和桌面/手机布局。验证通过删除本次临时测试，保留现有测试；运行生产构建。不格式化无关代码，不创建提交。

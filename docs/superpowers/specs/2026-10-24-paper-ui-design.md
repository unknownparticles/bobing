# 今晚谁是状元：浅色新国风界面

用户在三种实际对比稿中选择 A「浅色新国风」。本次实现这一方向的首页、角色选择、剧情与对局界面。

## 已确认的视觉

- 米纸底色、墨绿文字、朱砂主操作、青瓷骰碗，使用一致的字号、线条和圆角。
- 对局上方为五名对手的近景头像与分数，中间为主要骰碗与结果，下方为本人状态与操作。
- 不把全身立绘缩成小卡；角色选用界面与剧情保留较大的立绘，桌面使用头像裁切。
- 掷骰是最明显的操作；奖池移为辅助信息，窄屏放在主场景之后。
- 桌面和手机均要看清骰型、结果、当前行动者；操作条不得与结果重叠。

## 实施边界

界面采用现有 React、CSS、Lucide 和角色 WebP，不增加 UI 框架。期间发现仓库新增独立 Game、商店与重掷规则；用户随后确认保留这些最新玩法并统一为 A 风格。原有判奖、轮次与道具校验继续由 src/game 的 reducer 与 hook 处理，本次不新增联机、音频、终局或机器人策略。

公开展示组件放在 src/ui，主题令牌与响应式样式放在 src/paper-theme.css。src/game/Game.jsx 保留动画、动作权限和状态管理，接入 PaperGame 呈现。轮间商店继续使用 Shop；目标选择使用原生 dialog 保持键盘焦点与背景隔离。

## 参考仓库与取舍

- https://github.com/osselets/knucklebones ：已核实 React/Vite 项目并查看 AI 对局，借鉴分数、对手与操作区域的清晰分工。
- https://github.com/3d-dice/dice-box ：已核实 MIT、React demo 与在线演示，参考骰子的立体质感；本次使用轻量 CSS/SVG。
- https://github.com/TyconXon/Weblatro ：已打开在线版本，参考侧栏计分与中央玩法区，不复用其素材和扫描线效果。
- https://github.com/libnoname/noname ：已核实当前仓库、layout/theme 结构与项目说明，作为中文角色桌游结构参考；未运行完整本地版本。

## 验收

1. 首页 → 角色选择 → 两段剧情 → 对局可完整进入，昵称和头像进入对局。
2. 掷骰、机器人回合、技能按钮仍可操作，等待时禁用状态清晰。
3. 至少检查 390×844、320×740、1280×720，无横向页面溢出，掷骰操作在首屏可见。
4. 结果与头像、底部操作条不重叠；减少动画偏好继续有效。
5. 生产构建与现有测试检查，以实际输出为准。纯视觉改动不增加镜像实现的测试文件。

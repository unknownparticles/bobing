# 遇见图鉴与玩家公开详情

用户已通过选择器确认 A 方案并授权实现。

- 图鉴沿用长期档案，提供卡牌、技能、角色分类，首页和对局均可打开。
- 卡牌发现来源：本人货架、本人的获得、任意玩家公开使用。对手货架和未使用手牌不构成发现；对手公开使用不计为本人使用，也不触发本人成就。
- 技能读取当前规则中的主角专属技能和章节职业技能；入桌时记录实际出现的角色和公开技能。章节角色按章节身份记录，避免同一同事在不同章节的称呼、职业数值被混用。角色身份独立于立绘，缺少立绘时使用既有通用头像。
- 玩家详情由当前玩家 ID 查询实时数据：奖项总份数、各奖项数量、积分、公开技能、当前公开效果和本桌已使用卡牌说明。不读取或呈现对手手牌、未使用卡牌数量。
- 沿用原有图鉴的未发现/未解锁状态，提供仅看遇见过筛选；遇到但本人尚未解锁的卡牌仍可查询规则。技能和角色展示已经遇见的内容。
- 原档案缺少新增收集字段时补为空数组；已有卡牌、成就、称号、周目和存档只读保护继续有效。
- 使用原生 dialog 支持关闭、Escape 与焦点隔离；图鉴覆盖对局时保持原对局挂载，关闭后回到原桌。查看期间拦截摇一摇输入并隐藏可能遮挡阅读的顶层动效，奖项与效果仍按实时规则更新。

验证覆盖事件收录的公开边界、重复同步、旧档案、奖品转移后数量、分类和关闭交互、桌面和窄屏。新增临时测试通过后删除。不格式化现有代码，不执行 OHOS 检查。

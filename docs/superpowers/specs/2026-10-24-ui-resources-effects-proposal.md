# 界面资源、按钮与技能释放表现方案

用户希望继续完善网页图标、界面设计、按钮及技能释放动画，延续已确认的米纸、青瓷、朱砂与墨绿视觉。

用户已确认全套优化与约1100ms轻快动效，现已落地。见 [实际验收](../../ui-preview/ui-resources-effects-verification.md)。原始方案保留如下。

## 当前检查结果

- favicon、ICO、Apple Touch、PWA 普通与 maskable 图标、分享封面已存在并接入，沿用同一骰碗形象。
- 56 张商品插画已接入商店，手牌与选牌详情仍主要使用 CardIcon 线性图标。
- 按钮已有基础样式，但主次、悬停、按下、选中、禁用与键盘焦点可进一步统一。
- EffectLayer 已跟踪真实来源/目标头像、离屏浮动端点及真实结果；主要复用飞线、徽记和光圈，总时长 1100ms。

## 建议落地范围

1. 资源：检查现有网页图标在 16/32px 与安装场景的辨识度，界面内标识与现有骰碗资源保持关联。保持现有部署路径处理。
2. 界面：主入口、模式选择、对局操作、手牌抽屉与商品详情统一纸面层次、间距和装饰密度。先量容器，再复用素材；56 张插画继续保持 16:9 完整展示。
3. 按钮：明确朱砂主操作、青瓷次操作、轻量辅助操作；补齐悬停、按下、选中、不可用原因与焦点表现。手机触控目标至少 44px；选择和禁用状态同时通过文字与轮廓表达。
4. 手牌：列表与详情复用现有商品插画，卡名、数量、可用时机、目标选择和确认按钮由真实状态渲染；小尺寸徽记继续保留矢量清晰度。
5. 释放：使用真实事件的商品 ID 展示对应卡面，配合六类视觉语法；事件结果、来源和最终目标不从图案猜测。

## 六类释放动画

| 类型 | 表现 |
| --- | --- |
| 改骰 | 卡面短暂亮起，青瓷环围绕骰碗，骰子变化后收束 |
| 抢夺与资源转移 | 奖章或铜钱沿真实来源到获得者移动，到达后给出数值反馈 |
| 防御与抵挡 | 目标头像出现青瓷护罩，被挡攻击在护罩边缘消散 |
| 反弹与替身 | 轨迹折返或改向真实最终目标，保留双方姓名和状态标签 |
| 牵缘与神明祝福 | 红线连接双方；自我祝福使用局部神明卡面与金色印记 |
| 场地 | 从桌面中心展开云纹或波纹，显示场地名并收束到现有状态条 |

状元转移继续突出真实原持有人与新持有人。手牌弹窗打开时，释放效果仍在顶层展示，不抢焦点、不截获按钮点击。连续事件按原队列逐条呈现，确认和消耗由规则层负责。

## 节奏选项

- 推荐轻快版：沿用每条事件约 1100ms 的时长，通过内部节奏区分起手、移动、命中与收束，不额外延长等待。
- 强表现版：重点技能约 1800ms，增加卡面停留与命中展示；会延长对局等待，需要用户明确选择。
- 也可先完成资源和按钮，再单独制作释放动画。

## 验收

检查桌面、平板、390px/320px 手机布局，重点检查手牌插画比例、关闭与确认按钮、事件端点、屏幕边缘和弹窗遮挡。逐类验证真实发动、成功、抵挡、反弹、替身与场地反馈。减少动画偏好下保留静态信息，关闭运动与闪烁。

沿用现有 React、CSS、SVG 与图片素材。新增生图仅在确实缺少栅格素材时使用原已授权 API；矢量图形与动画时序由代码实现。保持其他正在进行的修改。

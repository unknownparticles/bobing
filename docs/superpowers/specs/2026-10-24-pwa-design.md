# 博饼 PWA 设计

用户确认采用“可安装 + 完整离线”：沿用“今晚谁是状元”名称、博饼短名称及现有骰碗图标，安装后以独立窗口运行。

采用 vite-plugin-pwa 自动生成 Web App Manifest、注册脚本和 Workbox Service Worker。清单使用相对 id、启动地址及作用域，适配根目录与 GitHub Pages 的 /bobing/ 子目录。提供 192、512 像素普通图标、512 像素 maskable 图标及 Apple 触摸图标。

首次联网时预缓存构建页面、脚本、样式和所有游戏图片，确保未浏览过的角色和商店也可离线显示。缓存安装完成后支持断网重新打开和完整游玩。开发服务器不注册 Service Worker。离线能力不包含对局持久化。

新版本等待所有旧窗口关闭后激活，不主动刷新游戏；激活后清理过期预缓存。使用生产构建、现有测试及真实浏览器验证根路径、/bobing/ 路径、安装条件、全资源缓存和离线进入游戏。

# 三种模式与故事线实施计划

**Goal:** 首页可选择故事、快速、经典模式，规则和剧情完整闭环。

**Architecture:** 在现有 reducer 中保存 match 配置；由模式模块提供章节、人数、轮数和座位。App 负责章节切换，Game 负责单局状态，展示层读取当前模式。

**Tech Stack:** React、现有 CSS、Lucide、Vitest、Playwright，无新增项目依赖。

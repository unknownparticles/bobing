# 生图新国风 UI 落地计划

**Goal:** 将已确认的浅色青瓷对局、墨绿卡牌商店落地到真实 React 页面。

**Architecture:** 沿用现有展示组件与规则状态。新增独立视觉样式文件、静态插画映射和压缩 WebP 素材；文字、人物、骰点、价格及操作全部由现有组件渲染。

**Tech Stack:** React、CSS、Lucide、Python/Pillow 素材切分、现有 Vitest 与 Playwright。

在当前工作区顺序实施，保留已有未提交修改；用户已确认方向及参考图，不增加实施方式确认。

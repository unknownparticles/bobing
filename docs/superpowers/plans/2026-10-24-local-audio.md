# 本地合成音频资源实施计划

**目标：** 按已确认的国风轻快、无人声风格，离线制作 3 首背景乐和 19 个音效。

**方案：** Python 与 NumPy 合成拨弦、笛音、打击乐和物理碰撞近似声；背景乐用 FFmpeg 编码为 MP3，短音效保留 PCM WAV。资源清单提供稳定 key、实际文件路径、时长和来源。仅交付资源与试听页，游戏播放接入另行处理。

**工具：** Python 3、NumPy、FFmpeg、FFprobe；不添加网站运行依赖。

- [x] 新建 `scripts/generate-audio.py`：固定随机种子、循环编曲、无声尾硬切的音效、文件输出与资源清单。
- [x] 生成 `public/audio/` 下 22 个音频文件、`manifest.json`、原生音频控件试听页与资源说明。
- [x] 使用 FFmpeg 完整解码所有音频，核对实际时长、峰值、非静音及背景乐 PCM 循环边界，保存 `docs/audio-verification.json`。
- [x] 更新 `docs/audio-resource-plan.md` 的实际状态和资源格式，并执行网站构建检查公开资源可正常复制。

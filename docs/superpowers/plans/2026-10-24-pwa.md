# PWA Implementation Plan

**Goal:** 为博饼增加用户已确认的可安装和完整离线能力。

**Architecture:** 使用 VitePWA 生成清单、Service Worker 和注册脚本；使用相对地址兼容部署子目录；新版等待旧窗口关闭后激活。

**Tech Stack:** React、Vite、vite-plugin-pwa、Workbox。

- [x] 从现有 SVG 生成普通 PNG、maskable 和 Apple 图标，保持品牌一致。
- [x] 在 README.md 说明安装、首次缓存、更新以及无对局存档的边界。

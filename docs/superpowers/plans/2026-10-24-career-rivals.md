# 章节职业对手实施计划

> **For agentic workers:** 使用 subagent-driven-development；规则集成由主代理负责，独立界面任务交给子代理，完成后进行规格与质量审查。

**Goal:** 实现已批准的十九名章节对手、十项职业技能、职业采购偏好与真实电脑打法。

**Architecture:** `rivals.js` 管角色与章节名单，`careers.js` 管职业资源和统一触发，`career-actions.js` 复用效果层完成主动技能及电脑选择。现有 reducer 连接入席、轮初、行动、正式结算、夺奖、购买和轮末事件；UI 只展示真实状态。

**Tech Stack:** React、现有 reducer、Lucide、Vitest、Vite；沿用 CSS 主题。

- [x] 名单与临时规则测试：为 `createPlayers(profile, count, match)` 的三章人数/名单、组内无天赋、部门三技能、公司九技能、重开和通用模式隔离建立失败用例。新增 `src/game/rivals.js` 并更新 `modes.js`、`main.jsx`、`archetypes.js`。
- [x] 职业规则：新增 `careers.js` 与 `career-actions.js`，临时测试覆盖老板40/+10、人脉转移一次、资历正式结算、财务余额利息、首购减5、销售一次补牌、调度次数/先手、测试单骰±1、行政最低库存补给、风控一次反弹。在 `state.js`、`effects.js`、`archetypes.js` 中接入，非法动作返回原状态。
- [x] 电脑行为：`bots.js` 根据固定职业选择购物与出招；组内采购白名单；结果按公开奖池收益校验；`Game.jsx` 快照包含真实职业资源。所有随机数沿用动作注入。
- [x] 角色界面：新增 `RivalDetails.jsx` 与职业样式，`PaperScreens.jsx` 展示章节阵容，`PaperGame.jsx` 对手按钮打开详情；展示技能全文、状态、人脉对象、资历、金币和次数，补充职业台词。

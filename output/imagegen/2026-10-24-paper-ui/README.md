# 对局页与商店：新国风 UI 参考图

用户已选择优化对局页和商店，延续浅色对局、墨绿商店的现有方向，提升插画和材质并保持全站一致。

## 生成配置

- 调用方式：imagegen 技能的 CLI，通过用户指定的 API 服务生成。
- Base URL：`https://api.openai-next.com/v1`。
- 模型：`gpt-image-2`。
- 请求尺寸：`1536x1024`；质量：`high`；格式：PNG。
- 密钥运行时从用户指定的桌面文件读取，不保存到项目。
- 完整提示词：[对局页](prompts/game.txt)、[商店](prompts/shop.txt)。

## 设计意图

对局页保留五位对手、青瓷骰碗、右侧奖池和底部操作区。通过墨绿文字、朱砂主操作和克制的纸张纹理提高辨识度；插画让位于骰点、回合提示和结果。

商店保留左侧盘缠与操作区、右侧三个货架。八张商品卡同时可见：两张神明、三张技能、三张场地。插画分别表达商品含义，价格与购买入口独立清晰，离店按钮突出。

## 后续落地原则

- 参考图用于确认视觉；页面中的文字、价格、库存和按钮继续由 React 根据真实状态绘制。
- 素材应拆分为桌面装饰、纹理或单独插画，不把整张界面图片当作可操作页面。
- 保留规则层的判奖、购买、目标选择、供奉、刷新和场地提交行为。
- 保留现有角色资产；图中人物仅用于表现布局和插画风格。
- 检查桌面与手机布局，确保操作区、卡牌价格与详情可用，尊重减少动画偏好。

图中的示例数字与商品组合用于视觉构图，不构成对实际游戏配置的修改。

## 已落地

八张卡牌插画与纸纹已从参考图拆分为 `public/art/shop/` 内的 WebP，卡名和价格没有烘焙到素材中；门牌上的生成错字已在本地修正为“暂离”。素材与生成图分开保存，页面只加载压缩切片。

补齐完整牌库图集的请求因需要向第三方 API 发送完整目录及效果说明，被自动审批拒绝；没有生成这四张图集，也没有继续外发目录。其他商品保留现有 SVG 徽记。

实际页面与验证见 [验收记录](../../../docs/ui-preview/artisan-ui-verification.md)。

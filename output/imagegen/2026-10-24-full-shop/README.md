# 整库插画与比例修正

用户已明确授权通过原 API 服务补齐整库，并要求先测量比例，修正神明显示尺寸。

## 测量与生成规格

1280×720 原神明插画框约 198×74，即 2.67:1，原图 191×181，`object-fit: cover` 裁掉大半人物。手机与大屏还使用不同的插画比例。

新规格：所有卡面和详情采用 16:9 插画框，图片完整等比展示。1280×720 实测神明约 199×112、技能约 203×114；390px 手机神明约 141×79。详情宽度随屏幕变化，保持 16:9。

每幅生成插画为 512×288，以等宽两列图集生成，再按固定坐标拆分，不从完整 UI 效果图抠图。神明采用完整头饰、腰部以上、双手与法器均可见的横向构图，主体四周保留安全边距。

调用：用户指定的 `https://api.openai-next.com/v1`，`gpt-image-2`，imagegen CLI。密钥仅在运行时从用户指定文件读取。

完整视觉描述见 `subjects.json`，各图集最终提示词见 `prompts/`。本目录保留图集原图与切分清单，网页使用 `public/art/shop/full/` 下压缩 WebP。

## 实际采用与修正

- `manifest.json` 为图集单元格与商品 ID 的映射。首批神明图未满足安全边距，最终采用两张 `gods-*-safe.png` 的完整坐像。
- `overrides.json` 指定三张单独修正的场地图：五福临门、七星高照、八仙过海；最终图分别为准确的五、七、八颗骰子。
- `scripts/build-shop-art.py` 先校验全部图集和纠正图，再切分、压缩并生成前端索引；错误输入不会覆盖已通过的素材。
- `contact-1.jpg` 至 `contact-4.jpg` 展示最终采用的 56 张插画。全部 WebP 合计 2,228,300 字节。
- `measure-layout.json` 保留接入后的六种屏幕测量；实际验收记录见 [full-shop-art-verification.md](../../../docs/ui-preview/full-shop-art-verification.md)。

使用 imagegen CLI 模式生成，未向前端添加 API 调用或密钥；卡名、价格和效果说明继续由 React 渲染。

## Why

现在的对局画面是俯视的 6 人圆桌。碗只有 310×145,骰子 36px,而座位、顶部条、6 格奖池占掉了大部分注意力。配色是低对比的橄榄和灰绿,字号多处只有 8 到 10px,结果只用桌下一行小字提示。美术也不统一:像素骰子、CSS 椭圆桌和汉字方块头像混在一起。结果是玩家没有视觉焦点,也感受不到掷骰那一刻的悬念和奖励,没有兴致玩下去。

这个变更先做一个场景竖切片,让玩家一打开就能看到差别,再决定后续玩法怎么接。

## What Changes

- 对局画面改为近景单桌舞台:上方是对手陈主管(头像加台词气泡),中间是大瓷碗和 6 颗大骰子,下方是一个主按钮。删除 6 人座位环和 6 格奖池。**BREAKING**:对局界面不再展示 6 人围桌,技能按钮从舞台移除。
- 引入"夜色红金"设计令牌(颜色、字号、间距、圆角、阴影),全部写成 CSS 变量;最小正文字号 12px,主按钮字号不小于 18px。
- 骰子改为 CSS 3D 立方体,6 个面各一张 SVG,1 和 4 为红;碗做成后壁、骰子、前沿三层遮挡。
- 掷骰演出分段:摇碗、抛出、逐颗落定;点数在动画开始前就已确定,动画只负责表现。
- 结果反馈按奖项分档:小奖轻提示,中奖加震屏与金光,对堂与状元加大号印章,状元加全屏烟花。
- 用 WebAudio 合成骰子、落定、中奖和状元音效,静音按钮真正生效。
- 对手陈主管根据结果显示不同表情和台词,图片素材有固定位置,缺图时使用 SVG 占位。
- 首页点击开始后直接进入舞台,不再经过昵称注册页和剧情页。
- 舞台带一个临时的"练习桌"循环:每桌 3 次摇碗,累计得分,用完后可再来一桌。它仅用于让切片可玩,后续由肉鸽主线替换。

## Capabilities

### New Capabilities

- `design-tokens`: 夜色红金的颜色、字号、间距、圆角、阴影令牌,以及最小字号、触控尺寸和对比度要求。
- `scene-layout`: 近景单桌舞台的信息层级、手机竖屏布局、桌面适配、首页直达舞台、练习桌循环。
- `dice-roll-presentation`: CSS 3D 骰子、碗的分层、分段掷骰演出、结果先定后演、跳过动画、减少动态效果。
- `result-feedback`: 奖项分档反馈、印章与分数滚动、对手表情与台词、音效与静音。

## Impact

- 代码:`src/main.jsx` 的对局视图整体重写。建议拆成 `src/scene/` 下的组件(`Stage`、`Bowl`、`Die3D`、`Opponent`、`ResultStamp`、`Fireworks`),样式拆出 `tokens.css` 与 `scene.css`,不再使用压缩成单行的 CSS。
- 依赖:不新增运行时依赖。动画用 CSS 与 Canvas,音效用 WebAudio。本阶段不引入 Motion、Zustand、three.js。
- 素材:新增 `public/characters/` 约定目录,放陈主管的表情图;缺图时有占位。
- 与现有变更的关系:`complete-bobing-rules-and-endgame` 里的 `bobing-rules` 仍然有效,切片会复用其中的 `evaluateRoll`。该变更中的 `prize-pool`、`game-endgame`、`player-skills`、`bot-personalities` 以 6 人围桌为前提,与本变更冲突,后续在肉鸽主线变更里重做,本次不删除。
- 不涉及:肉鸽主线(遗物、特殊骰子、Boss 规则、难度阶梯)、变现、主角生成、联机。
